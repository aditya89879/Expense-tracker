# Expense-tracker
Expense Tracker Dashboard

Developed an Excel-based Expense Tracker for the year 2025 to record, organize, and analyze personal expenses in a structured manner. The project was designed to help monitor spending patterns and maintain financial records efficiently throughout the year.

Used Excel functions such as VLOOKUP, XLOOKUP, HLOOKUP, SUMIF, and COUNTIF for data organization, calculations, and category-wise analysis. Also created an interactive dashboard using Pivot Tables and Pivot Charts to present expense summaries and spending insights in a clear and user-friendly format. Overall, I gained practical experience in data handling, financial tracking, and dashboard creation using Microsoft Excel.
